# 内容检查与答辩准备

## 论证检查

逐章检验：研究问题是否回答？证据是否支持该强度结论？机制是否有替代解释？案例效果是否可归因？建议是否对应发现？摘要是否反映最终正文？

关键失败项：编造来源/数据/调研；相关性称因果；把他人调查说成自己开展；把未来方案写成已验证；缺关键定义或分母；模型有名无实。修复前不能称“可提交终稿”。

## 数值与结构

核对所有正文数字与图表，单位与年份，比例分母，表格合计，统计标记与区间；检查重复章节号、图表号、引用号，正文—目录—思路图一致性。无可用原始数据时不能声称重新算过结果。

## 答辩卡（用户需要时）

| 可能问题 | 回答必须包含 |
|---|---|
| 为什么选这个问题 | 场景与痛点证据、决策价值 |
| 为什么选这些案例 | 选择标准、比较维度、代表性限制 |
| 为什么用这个模型 | 对应问题、必要输入、相较替代法的理由 |
| 数据可信吗 | 来源、样本、清洗、口径、缺口 |
| 是因果还是相关 | 识别条件、替代解释、检验与限制 |
| 建议能落地吗 | 责任人、资源、前提、指标、风险 |

答辩回答引用实际章节与图表编号。不要编造答辩所需材料；缺失则列补证任务。
