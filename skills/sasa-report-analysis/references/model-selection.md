# 让模型服务问题

| 问题 | 可用框架 | 必要输入 | 应有产物与边界 |
|---|---|---|---|
| 外部环境如何影响行业 | PEST | 具体政策/需求/技术证据 | 变化→作用路径→行业影响；不只罗列背景 |
| 行业内谁创造/获取价值 | 价值链、五力 | 主体、成本/收益、渠道/竞争证据 | 价值节点、议价与瓶颈；无证据不量化强弱 |
| 主体的战略如何取舍 | SWOT→TOWS | 内外部证据与约束 | 有优先级的策略；避免四格空话 |
| 某模式如何起作用 | 机制链、逻辑模型 | 主体、行为、中介变量、结果 | 明确因果假设与替代解释 |
| 多主体形成何种反馈 | CLD 因果循环 | 变量定义、有方向关系与依据 | +/−、R/B、时滞；定性反馈不等于实证因果 |
| 激励为什么不一致 | 委托—代理 | 角色、信息、目标、约束 | 激励冲突与制度方案；数学求解须真实推导 |
| 样本怎么看待问题 | 描述统计、交叉分析 | 实际问卷/访谈数据与抽样说明 | 分布、群体差异、限制；显著性不得编造 |
| 政策是否带来效果 | DID/匹配/SCM 等 | 原始面板/时序、对照、处理时间、可辩护假设 | 实际估计及诊断；没有条件改为研究计划 |
| 市场之间怎样联动 | VAR/溢出测度等 | 足够时序、变量定义与稳定性条件 | 实际结果与统计限制；不因参考用了就套用 |

每个模型在正文回答四点：为什么选它、输入是什么、得到什么、不能说明什么。模型数不作为质量指标。

行业/案例报告常只需两三个互补框架。无法取得模型输入时明确证据缺口，改用比较或机制推演；不能把“高级模型”当装饰，也不能写不存在的稳健性检验。
