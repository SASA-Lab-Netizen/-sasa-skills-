# 听课内化与行动

将用户提供的学习材料整理成简洁的收获与可执行行动。忠实原意；听不清或上下文不足处标注不确定，不虚构讲者观点或事实。

1. 理解并清理转写错误和重复语句；无法确定的内容保留疑问。长材料先分段梳理再合并。
2. 用一句话概括核心收获，选择最重要的知识点，用易懂语言解释，并区分课程观点与自己的补充。
3. 根据用户的目标与时间，将知识转化为少量可观察的动作。可按“今天可做、本周尝试、长期习惯”分层；每项写清做什么、何时做、如何判断完成。时间和周期依实际情况调整。
4. 给出一个适合持续实践的微习惯及复盘问题；用户只需要摘要或行动时，按其需求裁剪。

可以先使用 `sasa-lecture-recap` 形成完整复盘，再用本技能提炼行动；也可以直接从原始材料开始。整理基于原 `cc-听课内化器`。
