# 课程学习与内化｜组合指南

1. 准备课程笔记、讲座或播客转写，以及希望解决的问题。
2. 使用 `sasa-lecture-recap` 整理课程主线、核心观点和案例，形成可阅读的复盘。
3. 使用 `sasa-learning-action` 把重点变成适合自己时间和目标的具体行动。
4. 拿真实行动复盘效果，再调整行动清单。需要分享时检查课程资料的授权及个人信息。

示例：「请使用 sasa-lecture-recap 整理这份听课稿，再用 sasa-learning-action 帮我列出今天和本周各能做的一件事。」

两份技能分别根据 `cc-lecture-recap-doc` 和 `cc-听课内化器` 整理；导入时保留完整文件夹。
