# 用户调研与竞赛图表：组合使用

1. 使用 `sasa-user-research` 设计访谈和记录表，明确目的、知情同意和验证问题。
2. 完成访谈后，用真实原话、来源及受访者编号汇总观察，保留相反意见和样本限制。
3. 使用 `sasa-business-workflow` 将证据用于判断需求、竞争、可行性和风险。
4. 用 `sasa-competition-figures` 将经核实的结果整理成需求图、证据链或风险矩阵；定性图注明判断口径，未经统计的数据不能画成总体占比。

安装时保留每个技能目录内的 assets 和 references；matplotlib 绘图需要 Python 与 matplotlib，以及可用的中文字体。

示例：「使用 sasa-user-research，为我的校园二手平台设计 30 分钟访谈提纲和记录表。」完成真实访谈后：「使用 sasa-competition-figures，根据这份匿名证据台账制作需求验证流程图，并标明资料来源。」
