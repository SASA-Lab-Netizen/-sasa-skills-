# 从方案到路演 PPT

面向听众和演示目标，把资料中的论点及证据整理为可编辑演示文稿；不虚构数据、案例或成果。

1. 收集受众、目标、场景、时长或页数、已有资料、交付格式和视觉约束；缺失信息可注明假设。
2. 提炼一条叙事主线，组织背景与问题、洞察与证据、方案、价值、可行性及行动；按任务适当调整，而非套固定页数。
3. 形成逐页清单：每页结论标题、关键信息、证据与来源、推荐图表或版式、讲述重点；用内容决定版式，避免每页同构。
4. 确定字体、配色、版式和信息层级；在适用时使用可编辑文本框、形状和表格。图片占位及未经确认的数据要明确标示。
5. 生成前先核实所用工具与依赖；要制作可编辑 PPTX 初稿时，可运行下方脚本，随后渲染检查页面并修正溢出、乱码和数据来源。示例只是起点，不代表设计已验收。

## PPTX 脚本

脚本依赖 Python 及 `python-pptx`。用 `python scripts/generate_pptx.py --example > spec.json` 查看 JSON 示例，再运行 `python scripts/generate_pptx.py spec.json -o output.pptx`。支持封面、目录、章节页、内容、四宫格、图文占位、三卡片及表格；图文页为图片占位框，需要自行替换。文字和表格由 PPT 对象生成，但实际效果与字体取决于环境。
