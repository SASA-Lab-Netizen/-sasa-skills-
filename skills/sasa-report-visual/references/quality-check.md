# 输出检查

## 必须修复

- 缺字、乱码、内容裁切、对象重叠、未标注单位/来源的关键数据图。
- 图中内容与正文数值不一致；样本分母混用；把示例数字标成真实结果。
- 章节重号/跳号，图表编号重复，正文交叉引用缺失，目录页码未更新。
- 图题/图/来源断到不同页面；表头丢失；标题后没有正文。
- 目标尺寸下图中文字不可读：先拆图与简化，再放大；不能仅提高分辨率。

## 五项人工判断

1. 颜色：整篇角色色是否一致？风险色是否被装饰滥用？
2. 层次：缩略图能否分出章标题、结论、主图和正文？
3. 逻辑：研究思路图是否展示输入、方法、输出的递进？
4. 密度：是否有不必要大空白或过度拥挤？长图是否应横向/附录？
5. 证据：每张图是否回答问题并可追溯，而不只是装饰？

仅有“很高级”的主观评价不能作为完成证据。交付时说明实际生成格式、已渲染检查的页数、尚待补充的数据或素材。
