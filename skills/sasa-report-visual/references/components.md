# 页面与组件库

## 页面类型

1. **封面**：主题画面占 45–65%，主标题与副标题独立文字层，作者/版本/日期置次级区域。无比赛授权时不沿用比赛徽标、校徽与他人姓名。
2. **摘要**：一句核心答案；问题、方法、发现、意义、限制；底部关键词。只加粗最关键结论。
3. **研究思路**：四至五条横向泳道，左侧阶段，中央“问题/方法/证据”，右侧输出；下一阶段接收上一阶段输出。用箭头连接递进，不能仅放目录框。
4. **正文证据页**：编号标题→结论句→证据图或比较表→解释与限制。图附近正文必须明确“该图支持什么”。
5. **案例页**：事实卡（主体/时间/情境）→流程/机制→效果证据→失败边界→启示。
6. **实证页**：假设/变量/样本→模型→结果图表→经济意义与方法限制；详细推导和大量稳健性表移附录。
7. **附录**：问卷原题、访谈提纲、编码、变量口径、推导、补充表；正文用明确编号回指。

## 图表组件

| 组件 | 构成 | 关键约束 |
|---|---|---|
| 证据图框 | 顶部编号与题名、细线、主图、细线、来源与口径 | 不在图内再重复长标题 |
| 比较表 | 深色或主题色表头、浅色交替行、主标签列 | 数字右对齐；文字左对齐；禁止每格厚黑框 |
| 回归表 | 变量列、模型列、系数/标准误、N、固定效应、注释 | 星号与检验意义如实解释；不伪造估计值 |
| 问卷双面板 | 左认知/分布，右渠道/排序，题干摘要与结果 | 写 n、对象、时期、单选/多选；多选不要求合计 100% |
| 机制链 | 主体→动作→中间变量→结果，支撑条件置次级带 | 箭头有方向；“关系”与“因果”措辞区分 |
| 时间轴 | 3–6 阶段，顶部时间，中部动作，底部证据 | 同一尺度、明确预期与已发生阶段 |
| SWOT | 2×2 格，内外维度标签、每格少量证据 | 导出策略或决策，不能只有形容词 |
| 因果循环 | 变量节点、有向线、+/−、R/B 环路、时滞 | 仅在逻辑验证后绘制，不能用普通流程图冒充 |

## 同色化外部素材

纯装饰线性图标优先重绘成 `currentColor` SVG，统一笔触、视角和尺寸。获准使用的透明图标可调色，但不能涂改截图中的数据、品牌标识、地图图例或证据文字。外部数据图若有原数据，按本报告风格重新绘制并注明“据…重绘”；只有截图就保持原貌并统一外框，别猜值。

参考页只证明呈现方式；不能确认图标来自哪个网站，也不能据此宣称可商用。复用自己的基础几何图标或核实授权素材。

## 分页

图题与图不得分开；来源与图放同页；长表重复表头，跨页标“续表”；正文采用孤行控制。不要给所有段落 `break-inside: avoid`，否则产生大量空白。目录页码在最后一次渲染后更新。章节编号选 1/1.1/1.1.1，内部列表再用（1）；不混用三种章节体系。
