# 封面、场景插画与生图

## 从参考借鉴的三种封面构图

- 科技蓝：深蓝黑底，行业实体（汽车/城市/设备）与可信数据通路形成主视觉，上方留标题区。参考现学现卖 PDF p1。
- 深蓝金：深蓝底、金色几何切面、中心行业生态插画，下半部标题；参考金桔司康 p1。
- 摄影橙：主题照片（实物/成长/产业）位于上半部，白底正文信息区与橙色边界；参考争当分子 p1。

这些是视觉构图观察，无法从成品确认原封面是否由 AI、素材库或人工制作。

## 生图提示词模板

使用当前可用的 imagegen 工具，并按工具要求读取相关技能。新图与编辑的引用机制遵循工具规则。

**行业研究封面背景**

> A4 纵向报告封面背景，主题为【具体行业与核心机制】。使用【深蓝 #304562 / 金黄 #F7C526】统一色系，视觉主体是【具体实体】，通过【清晰的数据通路/行业协作结构】表现【报告主命题】。精致商务出版插画，克制的空间层次，清晰轮廓，避免通用握手、灯泡和堆叠硬币。画面【上方/下方】预留约【30%】平静区域供后续排入中文标题。不要文字、数字、品牌标识、校徽、水印，不画统计图或未经提供的机制关系。

**无文字场景插画**

> 白色或透明背景的横向行业场景插画，用【主色/浅色/灰】；【三类主体】在【实际场景】协作，视角与描边统一，主体互不遮挡，保留空白用于后期添加准确标签。不含文字、数字、统计刻度与商标。

透明切图必须启用透明背景；普通封面不启用。不要把 prompt 当成真实生图结果；无工具时交付提示词和封面排版源，说明插画尚未生成。

## 封面合成

主标题、研究副标题、作者、日期通过 HTML/Word/PowerPoint 文本层排入，不依赖图片生成中文。主标题建议 24–32 pt，副标题 13–16 pt，版本信息 9–10 pt。背景复杂则用稳定深色/白色标题板；不把整页都变成图片。

封面信息依赖用户材料：不继承比赛名称、队名、电话、邮箱、校徽或赛事标识。标题可以有短口号，但研究对象与问题必须明确；严肃报告不能仅剩“链通未来”一类模糊修辞。
