# 视觉规范：参考观察与建议参数

## 从参考中观察到的规则

五份 PDF 均为 A4 纵向（约 595×842 pt）。现学现卖、金桔司康、黄金矿工、金融矿工抽查的正文以宋体类字体 12 pt 为主；金桔司康图题/来源抽查约 10.6/9 pt。争当分子所抽查的机制页含 14 pt 文字，不能因此推断全书正文均为 14 pt。部分思路图整体是嵌入图片，PDF 文本层无法测量其内部字级。

共同设计：白底单栏长文；主题色标题；黑色粗体结论；同色表头与浅色条带；图示围绕同一主色展开；细横线把图与正文分开；页眉与页脚持续提供定位。封面允许强视觉，正文保持克制。

以下是提炼后的建议参数，不是对原件的精确复刻。

## 默认参数

| 项目 | 建议 |
|---|---|
| 页面 | A4，左右 20–23 mm，上 18–22 mm，下 18–20 mm |
| 正文 | 宋体/思源宋体 11–12 pt，1.45–1.6 倍行距，首行 2 字 |
| 一级标题 | 黑体/微软雅黑 16–18 pt，主色，段前 12–16 pt |
| 二级标题 | 13–14 pt，加粗，主色，段前 8–12 pt |
| 三级标题 | 11–12 pt，加粗；不能单独留在页底 |
| 图题 / 表题 | 10–10.5 pt，统一置上；如比赛指定另行遵守 |
| 来源 / 图注 | 8.5–9 pt，左对齐，紧贴图表；多行则自然换行 |
| 图中正文 | 最终页面上约 9–10 pt；8.5 pt 以下先简化或拆图 |
| 线条 | 0.5–0.8 pt 表格分隔，1–1.5 pt 主流程与箭头 |
| 正文宽度 | 约 164–170 mm；常规主图与正文对齐 |
| 并排图 | 两列等宽，间距 4–6 mm；放不下文字则改单列 |
| 强调 | 主要结论、机制、数字；避免整段黑体 |

中文正文与图中短标签分工：正文用宋体，图中优先无衬线提高小尺寸可读性；数字小数位统一，统计表数字按位对齐。

## 三种配色变体（近似提炼值）

| 变体 | 主色 | 深色 | 浅底 | 强调 | 适用 |
|---|---|---|---|---|---|
| 理性蓝 | #1764B7 | #203A5F | #EAF1FA | #31A5C7 | 行业、供应链、实证 |
| 深蓝金 | #D99A00 | #304562 | #FFF3CE | #F7C526 | 案例、机制、商业报告 |
| 活力橙 | #D96613 | #8A3D16 | #FFF0E5 | #F4B440 | 比较研究、创新业务 |

深蓝金在封面用深蓝大底，正文标题用深金；不要在白底上用浅黄小字。深色文字 #242A32，次级文字 #5B6572，边线 #DCE2E9，白底 #FFFFFF。

在同一报告内固定角色色：主体/核心=主色，条件/支撑=浅色，风险=少量红，其他=灰。同一主体跨图不换色。主色可调深浅但不用彩虹。

## 紧凑的含义

提高信息组织效率，不意味着挤满纸：图题→图→来源作为一块；相关图并列；降低无意义段后空距；用比较表消除重复叙述。保留段落呼吸、章节起始留白，禁止缩到无法阅读、裁图或隐藏溢出。原件有少量大留白，可改进而不必照搬。
