# 图示制作与数据图工作流

## 图示规格先于绘图

每张图至少写：目的、要支持的结论、图型、目标宽度、节点/数据、边/比较关系、颜色角色、题名、来源、限制。模型有理论名、假设、输入、输出、解释边界；无数据的方案图标“作者设计/概念框架”。

工具选择：SVG/PowerPoint 原生形状适合结构与流程；Python/电子表格适合真实数据图；复杂数学模型用 LaTeX 或矢量文字；AI 生图适合背景和概念插画。不能把所有图都转成一张 AI 图片。

## 研究思路图

按实际研究依赖组织：

`背景与研究问题 → 机制/假设 → 证据验证 → 综合判断 → 分主体建议`

案例归纳型允许：`痛点 → 案例验证 → 共性机制与新问题 → 治理/实施路径`。

每个阶段写清问题、方法、产物；箭头表达“哪个产物推动哪个阶段”。横向 3–4 栏，纵向 4–5 阶段；以阶段色带、浅底容器、主色产物框建立层次。不把每个三级目录全塞入。节点短标签建议每行 6–12 字；长解释留正文。

本技能脚本支持阶段泳道、等距流程、比较矩阵；复杂双向反馈应另外绘制 SVG，不能删边以迁就脚本。

## 统计图

- 趋势=折线，类别比较=柱/条，结构=堆积或少类别环形，关系=散点，估计与置信区间=系数图。
- 柱图通常从零起；非零截断明确说明；双轴慎用并标单位；预测区间用虚线/浅底，历史与预测分界清楚。
- 同一图共享口径、单位、时间和分母；百分比说明基数；数据缺失留空或注明，不补成零。
- 清楚标单位、时间、来源、样本与计算口径；有统计不确定性则展示区间。避免三维饼图和透视柱图，即使原件偶有采用。
- 直接标关键值，少量网格线，弱化坐标装饰。多系列依靠颜色+线型/标签区别。

## 问卷与访谈

展示题干摘要、选项、真实频数/比例和有效 n；原题、招募方式、调查日期、剔除规则放附录。便利样本不能推断全体人口。问卷没有结果时只交付问卷版式，不生成“有效样本”与百分比。

访谈编码表要区分受访者人数、提及次数、各群体频次分母。引用二手研究的访谈数据时写“该研究”，不能写“本团队访谈”。

## 图标

用几何线性图标表示主体（企业、资金、设备、文件、监管），统一 24×24 或 32×32 网格，描边约 1.5–2 px。不要用 emoji 作正式模型节点。图标辅助文字，不能代替实体名称。

## 导出

保留 SVG、源数据和规格 JSON；需 Word 插图时提供高分辨率 PNG 兼容版本并保留矢量原稿。在目标宽度核对文字；导出 300 dpi 位图不等于小字变得可读。
