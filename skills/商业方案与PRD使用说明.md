# 产品与商业方案组合使用

1. 使用 `sasa-business-workflow` 从赛题与用户需求出发，进行头脑风暴、验证、定位、落地及财务风险分析，整合成商业方案。
2. 产品方向相对明确后，使用 `sasa-prd-generator` 将目标用户、功能、业务流程与验收标准整理成 PRD。输出信息架构及关键流程图。
3. 写行业分析时可配合 `sasa-report-analysis` 和 `sasa-report-visual`。对于不确定的信息保留来源与待验证标记。

例：「请使用 sasa-business-workflow，基于我的赛题和访谈材料，提出三个方向，设计验证计划并评估财务风险。」

安装时请保留各技能文件夹内的 references 和 scripts。六步法来源和整理方式见技能正文；PRD 模板根据本地 cc-prd-generator 整理，不包含原有真实项目案例。
