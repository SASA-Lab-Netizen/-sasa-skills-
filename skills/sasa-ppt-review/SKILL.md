# 路演 PPT 诊断与优化

先读取原稿和用户目标，给出具体的逐页问题、影响与修改建议，再按授权范围修改文件。保存独立副本，保留原稿；核对关键事实和数据来源。

1. 了解听众、用途、时间、重点和编辑限制。提取页面顺序、文字、图片、表格和演讲者备注（工具可用时），并渲染查看每页，不能只凭文本判断视觉。
2. 检查叙事主线、标题是否表达结论、证据与来源、信息密度、页面层级、图表标注、字体可读性和整体一致性。按影响排序，区分事实缺口与设计建议。
3. 列逐页清单：页码、现有信息、问题、建议、所需资料和修改优先级。对无法读取的内容标注限制，不假装检查过。
4. 按用户要求修改：优先保留原有可编辑对象及多段格式；避免全量覆盖已有内容。重排或删页前核对唯一标识、页面顺序和文件关系。不要盲目修改底层 XML 或删除 ZIP 重复项；遇到结构异常应保留原稿并排查。
5. 最终重新打开并渲染文件，检查页数、顺序、文本、图片、表格、溢出与字体，列出仍需用户确认的缺失数据或图片。

来源：根据原 `pptx-reverse-optimize` 的逆向检查与优化经验整理，公开版省略了项目专属示例和具有数据损坏风险的自动修复方法。
