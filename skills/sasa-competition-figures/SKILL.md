# 竞赛图表工坊

根据目标读者和信息关系选择合适图型，交付可复现的绘图代码与清晰图像；输入数据、假设、统计口径和来源必须可追溯。没有数据时可绘制明确标注的概念图，不编造数据。

## 工作流程

1. 读取用户材料，列出图表目的、结论、数据或节点、单位、时间、来源、图型和目标尺寸；缺口明确标记。
2. 选择适合场景的工具；如用 matplotlib，可参考 [组件库](assets/common.py) 和 [样式指南](references/style-guide.md)。保留文字可编辑的 SVG 与适当分辨率 PNG；输出 PDF 时可同时设置 `pdf.fonttype=42`。
3. 每张图记录其输入、生成脚本及字体依赖。实际中文字体应根据本机可用字体选择；如果缺字应提示并换字体。
4. 核对数值、单位、来源与图注；检查裁切、文字重叠、颜色对比、布局及缩放后的可读性。不能只依赖脚本无报错，须查看实际生成的图像。
5. 在不确定视觉风格且图量较大时先出少量样张；用户已有明确方向时直接执行。交付图、源代码及数据来源说明。
