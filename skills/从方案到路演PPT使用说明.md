# 从方案到路演 PPT｜组合指南

1. 已有商业方案或 PRD 时，使用 `sasa-ppt-planner` 提炼演示主线、逐页内容和视觉规格。
2. 根据规格制作可编辑 PPTX；可选用策划器自带脚本生成初稿。安装 Python 与 python-pptx，运行 `--example` 查看输入示例。图文页为图片占位框。
3. 使用 `sasa-ppt-review` 检查叙事、证据、版式和每页可读性；按需要修改并渲染复核。
4. 需要图表可结合 `sasa-competition-figures`，所有数据及引用以原材料或可核实来源为准。

示例：「根据这份商业方案，使用 sasa-ppt-planner 设计一份 8 分钟路演的逐页大纲，再制作可编辑初稿。」

两份 Skill 整理自 `ai-ppt-planner` 和 `pptx-reverse-optimize`；策划方法参考其他作者的 AI PPT 经验，未包含参考提示词全文或未核实的素材。
