# 从想法到应用的提示词链

1. 明确目标用户、各页面功能、输入输出、交互、空状态和验收标准。能合理推断的注明假设，仅询问会影响实现的关键问题。
2. 标明真实与演示数据、本地保存与跨设备同步的区别；外部服务缺少配置时如实标记。
3. 将需求拆为可运行的第一版、测试、针对性改进、视觉与适配。按用户要求灵活调整顺序。
4. 对实际涉及的交互及保存、刷新、导入导出和移动端进行适当实测；记录已验证、未验证和受限事项，避免把静态演示描述为真实功能。
5. 整合为可复制提示词，列出目标、模块、边界、数据、交互、视觉及验收；后续改动保持已有数据和功能。

来源：根据 `cc-prompt-chain` 整理，原技能注明参考何锦成《WorkBuddy 个人专属工作台：完整提示词链路》。
