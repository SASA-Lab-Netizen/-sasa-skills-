# 课程复盘文档

把材料整理成读者能理解的知识复盘。先识别主题、讲者、核心观点和材料完整程度；材料不足时明确说明，不为凑篇幅添加讲者没有说过的内容。

1. 提炼主线和支撑观点，尊重原意，按阅读逻辑重组。可按核心认知、概念、方法、案例、应用和行动组织，章节依素材调整。
2. 用简洁语言解释关键概念；必要时使用对比表、结构图或例子，区分讲者原案例与整理者新举例。
3. 原话只有在确实逐字一致时加引号；转述和自己提炼的句子明确区分。数据及来源按材料标注，未经核实的说法不得包装成事实。
4. 结尾整理重点与适合用户的下一步；面向公开分享时注意课程资料的授权范围和隐私。
5. 按用户要求输出文本、Markdown 或文档；需要 Word/PDF 时使用可用文档工具并检查页面。行动清单可交给 `sasa-learning-action` 进一步细化。

整理基于原 `cc-lecture-recap-doc`，公开版保留主线梳理与忠实性原则，不强制固定篇幅、金句或段落数。
