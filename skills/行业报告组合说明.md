# 行业报告 Skill 组合

这组技能分两步：先用 `sasa-report-analysis` 明确研究问题、证据和章节，再用 `sasa-report-visual` 设计版式、封面与图示。也可单独使用。

1. 提供研究主题、目标读者、已有资料、时间范围和交付格式。
2. 对 AI 说：「使用 sasa-report-analysis，帮我建立研究问题、资料索引、证据台账和报告结构。」核对资料后再写报告。
3. 对 AI 说：「使用 sasa-report-visual，为确认的内容设计版式和图表，保留可编辑源文件。」
4. 检查关键数据、来源、图表和成稿的实际页面。信息不足时，标记待验证，不要编造。

把两个技能文件夹完整导入支持 SKILL.md 的 AI 工具；references、assets 和 scripts 需要保留相对目录。不同工具的安装位置不同。绘图脚本使用 Python，具体依赖和适用条件见技能文件。

来源说明：该系列由对五份用户提供的比赛报告的结构与视觉观察整理而成。仓库不包含原报告，样本中的事实未经全面核验，不应作为新报告的证据；参考索引用于说明设计观察的来源。
