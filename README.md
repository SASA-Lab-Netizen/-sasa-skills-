# SASA Skills｜飒飒的 Skill 积木箱

这里收集飒飒整理的 AI Skill，让好用的方法可以被重复使用。

## 技能目录

| 系列 | Skill | 用途 |
|---|---|---|
| 行动规划 | [想法变行动 SOP](skills/sasa-idea-to-sop/SKILL.md) | 将零散想法拆成可执行步骤 |
| 行业报告 | [报告内容与证据架构](skills/sasa-report-analysis/SKILL.md) | 梳理研究问题、证据、章节与论证 |
| 行业报告 | [报告视觉系统](skills/sasa-report-visual/SKILL.md) | 设计版式、图表和可编辑图示 |

[查看行业报告组合使用说明](skills/行业报告组合说明.md)。建议先做好内容和证据，再设计视觉。

## 使用方法

下载或克隆本仓库，将需要的完整 Skill 文件夹按 AI 工具的安装方式导入；保留其中的 references、assets 和 scripts 文件夹。也可以打开 `SKILL.md`，把内容交给支持读取指令的 AI。具体安装路径取决于工具。

例如：「使用 sasa-report-analysis，帮我梳理这个行业报告的研究问题和证据台账。」

## 来源与边界

想法变行动 SOP 根据飒飒现有的 `cc-idea-to-sop` 整理。报告系列基于对五份用户提供的比赛报告的结构与视觉观察；仓库不包含原报告，样本中的事实未经全面核验，不能作为新报告的事实依据。
