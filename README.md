# SASA Skills｜飒飒的 Skill 积木箱

这里收集飒飒整理的 AI Skill，让好用的方法可以被重复使用。

## 第一块积木：想法变行动 SOP

[查看 sasa-idea-to-sop](skills/sasa-idea-to-sop/SKILL.md)：把零散想法、笔记和经验，变成由浅入深、可以执行的步骤。

**试试这样说：**「我想开始做一个读书分享账号，但不知道从哪里下手。请帮我把想法变成可执行的 SOP。」

## 使用方法

下载或克隆本仓库，将 `skills/sasa-idea-to-sop` 文件夹按你的 AI 工具的 Skill 安装方式导入；也可以打开 `SKILL.md`，把内容交给支持读取指令的 AI 使用。具体安装路径取决于工具。

## 来源

本 Skill 根据飒飒现有的 `cc-idea-to-sop` 整理为独立分享版。
